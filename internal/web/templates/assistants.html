MCP is off on this hub

{{if $admin}}

To let people connect AI assistants, turn on the read-only MCP endpoint and publish it on the tailnet only. Add this to /etc/heimdall/heimdall.toml, with your hub's tailnet name:

[mcp]
enabled  = true
listen   = "127.0.0.1:8090"
base_url = "https://hub.your-tailnet.ts.net:8444"

Then publish it to the tailnet (never the internet) and restart:

sudo tailscale serve --bg --https 8444 http://127.0.0.1:8090
sudo systemctl restart heimdall

See docs/mcp.md.

Connect an assistant

This computer must be on the tailnet: {{.Endpoint}} answers only there.

{{if .Named}}This hub's connection is called {{.Name}}, so it sits beside connections to other Heimdall hubs.{{else}}Connecting to more than one Heimdall hub? Each one's connection needs its own name, or the second replaces the first. An admin sets it on each hub with sudo heimdall mcp set-name heimdall-acme, then sudo heimdall restart.{{end}} If a hub's name changes, remove the old connection and add it again.

Download the Heimdall extension

  1. Double-click {{.FileName}} to open it in Claude Desktop (or drag it into the window, or use Settings → Extensions → Advanced settings → Install Extension…), then click Install.
  2. Paste your token into the extension's Token setting. The Heimdall URL is already filled in with {{.BaseURL}}. Claude Desktop keeps the token in your system keychain.
  3. With this computer on the tailnet, ask Claude something like "what should I patch first?"

The extension is a small bridge that runs on your computer with Claude Desktop's built-in Node.js. It has no dependencies, and it sends your token only to this hub.
