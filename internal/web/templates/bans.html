Create the write token

Bans use a second token, separate from the read-only one. Open Cloudflare's token form, pre-filled (Zone > Zone WAF > Edit). Then add {{.TokenManual}} by hand: Cloudflare doesn't document its key, so the link can't include it. Scope it to the account, then store it on the hub with sudo heimdall bans set-token.
