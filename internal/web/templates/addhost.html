Wait for the first report

It arrives as soon as the installer finishes. After that the server reports hourly, about a minute after packages change, and 3 minutes after a reboot.

Report after deploys

To report right after a deploy too, end the deploy script (Laravel Forge's, for example) with this line. It returns at once and never fails the deploy.

sudo -n systemctl start --no-block heimdall-collect.service || true

The deploy user needs permission for exactly that command, without a password. Run this once on the server, with your deploy user in place of forge:

echo 'forge ALL=(root) NOPASSWD: /usr/bin/systemctl start --no-block heimdall-collect.service' |
  sudo tee /etc/sudoers.d/heimdall-collect
sudo chmod 0440 /etc/sudoers.d/heimdall-collect && sudo visudo -cf /etc/sudoers.d/heimdall-collect

Servers without systemd: see Report after deploys.
